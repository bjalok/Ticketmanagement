ANIMATION TIMING SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
useEffect watching agentSelectedTicketId.
On change: reset ALL state arrays to [] and all done-booleans to false.
Collect all timeouts in a timers[] array, return cleanup.

Phase timing pattern (adjust base delays per ticket type):
  phase starts at: previousPhaseDoneAt + 800ms gap
  each step appears: phaseStart + (stepIndex × 600ms)
  phase done: phaseStart + (stepCount × 600ms) + 400ms

Contact center ticket (t/233838887) full sequence:
  300ms   → Triage pre-check steps start
  pre done → enrichment questions shown
  [user clicks Approve] → 1800ms → context panel appears → check steps start
  check done → CTI steps start
  CTI done → dup scan steps start
  dup done → Recommendation: similar ticket steps start
  rec done → runbook steps start
  runbook done → troubleshoot steps start

Pipeline ticket (b/448326226) full sequence:
  300ms   → Triage dup scan starts
  dup done + 800ms → Investigate RCA steps start
  RCA done + 800ms → Recommendation steps start
  rec done + 1200ms → Lifecycle steps start
