ANIMATION TIMING SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Use useEffect watching agentSelectedTicketId.
On ticket select, reset all state arrays to [].

Pattern for each agent phase:
  const stepTimings = steps.map((_, i) => ({
    show: baseDelay + i * 600,
    done: baseDelay + steps.length * 600 + 400
  }))
  steps.forEach((step, i) => {
    timers.push(setTimeout(() => setSteps(prev => [...prev, step]), 
      baseDelay + i * 600))
  })
  timers.push(setTimeout(() => setPhaseDone(true), phaseDoneAt))

Typical phase timing:
  - Triage context check: starts at 300ms
  - CTI classification: starts after context check done
  - Duplicate scan: starts after CTI done
  - Investigate RCA: starts 800ms after dup scan done
  - Recommendation: starts 800ms after RCA done
  - Lifecycle: starts 1200ms after recommendation done
  Store all timeouts in array, return clearTimeout cleanup from useEffect
